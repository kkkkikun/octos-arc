## 3. 分题结论

- **a. 票×墙×燃料**：2 全票是上限（22h+18h）；燃料不对称，github 加、sheet 减（见上表）。
- **b. 冷启天花板 25-26**：加墙 >> 改顺序 > 换模型。换模型是否决项（燃率/稳定性未知，所有地板测算作废；除非本地 2h 复现"同墙+3 场景"，否则锁死 deepseek-v4-flash）。改顺序只做便宜的：依赖允许范围内按场景数加权先做多场景节点（main.py 纯排序，不碰内核）。判据：若 T1 20h 墙 sheet 仍钉死 25-26（±1），证实天花板非墙所致，T2 sheet 转保守（燃料砍到 $3 只收割），all-in github。
- **c. REQ-3/4 结构性红**：不选"剔除"也不维持"保留+停摆刀"，选中间路线——arc-policy.toml 加 quarantine = true：验收仍跑（保留信号），但 exit 非 0 不触发回边、不计停摆刀签名、不耗修复轮。省燃料保信号；T2 前若本地证明重播种假设成立再彻底剔除。
- **d. 代理测试 T2 前再扫 5 类**（每类 30 分钟，超时直接 quarantine 不修）：跨角色可见性（多角色需求代理 spec 是否真切双身份）/ 分页空态超长 unicode 公式错误值 / 时间时区（容器 UTC vs CST，加 mock 或放宽）/ 上传下载剪贴板（断言放宽到存在+大小>0）/ 40s 钟反噬（waitFor* >5s 改轮询+早退）。
- **e. 盈亏平衡**：公式正确，但分任务用。sheet 操作点阈值 ~0.77→取整 1 场景/美元（保守，防 B 未知）；github 操作点阈值 ~0.12 场景/美元，几乎永不停。燃料表不做 p-感知停机（绿标签簇状到达，错杀=暴雷），做 p-感知燃料：github $8 打满不设边际停机；sheet $5.5 + 人工判据（连续 90 分钟无新绿且已用>$4，人工决定是否提前交付，不交机制）。永远不用损 p 换 b；提前停只在"省的时间能换另一票 p"时成立。
- **f. 修复轮 prompt 加 5 条指位线**（verify_node.py stdout 回传处，system 前缀，一句话一条）：404 js/css + HTML 内容→查静态挂载白名单贴探针输出；子路由相对路径 404→改根绝对路径；Playwright Timeout 40s + 服务 log 无请求→先查 readiness；有状态对第二测红→查种子快照恢复不回滚；评审人/权限红→查种子账号独立性不放宽校验。
